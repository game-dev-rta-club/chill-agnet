# Resume work

Use this for incoming feedback or an interrupted session. Find
what has changed and choose useful work within the current agreement.

For feedback, use [Receive feedback](receive-feedback.md) to distinguish a
correction to current work from an independent request that can stay queued.
Skip work already completed; if all are complete, do not repeat the reply.
Interpret answers and annotations with their original question or Brief version.

Start with the supplied read command. `goal show --section context --format text`
on supporting versions gives scope, criteria, recent input and links to the
Brief and Letters. Follow the relevant links when they affect the next decision.
For other branches, use the filtered `goal review` index rather than reading
all histories. An older CLI can use `show` and `tree` from its help.

Use the [calling harness CLI route](../workspace/use-cli.md) when selecting work
or recording receipts. Select the Goal you will advance. Use existing agreement and evidence to decide
what comes next; waiting on one branch need not stop another. Reopen a Done Goal
only for actual remaining or newly agreed work. Preserve other Goals' queues
and manual pauses.

## When AutoContinue calls

Use [Continue autonomously](../auto-mode/continue.md). One request combines
choosing the next action with checking whether a decision to stop overlooks
entrusted work; there is no separate second review request.
