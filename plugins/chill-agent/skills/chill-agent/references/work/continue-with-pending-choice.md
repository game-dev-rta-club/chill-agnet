---
keyPoints: >-
  An unanswered choice blocks only actions that require its answer. Continue
  the same deliverable with a reversible provisional choice when authorized;
  preserve the decision for later without treating silence as consent.
---

# Continue while a choice is pending

Use this after asking a question or whenever an unanswered Letter seems to
prevent progress. A Letter records a decision, not a pause on the whole Goal.
Check the actual dependency before deciding to stop.

Name the next action toward the agreed outcome and what the missing answer
would change. Does it prevent producing or checking the work, or only determine
its final location, name or another reversible detail? Consider advancing the
same deliverable before looking only for unrelated tasks or more documentation.

When the work is already authorized, choose a provisional option that preserves
usable progress and is inexpensive to revise. Follow existing project conventions,
keep originals intact, and avoid dependencies on the unsettled choice. For
example, an undecided final Scene folder can leave final placement pending while
you save a working Scene in an appropriate project-local draft location and
continue building and testing it. Do not declare that draft the permanent rule.

Carry out the useful step now. Record the provisional choice, where the result
is saved, what was checked, and what would change after an answer in the Brief
or result Comment. Keep the existing Letter available when the final choice
still matters; do not ask it again or claim it was answered. Reconcile the
artifact with the reply when it arrives.

Reversibility does not supply missing authorization. Respect an explicit pause
or instruction to wait. Do not substitute a provisional action for permission
to publish, spend, destroy data, or change the agreed outcome. Where no useful
authorized step can proceed, identify the specific dependency and resumption
condition. Stop that part, not other work that can advance. If the outcome is
already achieved, do not create extra variants merely to remain busy.
