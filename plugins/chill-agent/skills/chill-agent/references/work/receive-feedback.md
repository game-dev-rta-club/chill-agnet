# Receive feedback during work

Keep new intent and entrusted work recoverable. Read the original messages in
order, including later corrections, before choosing what to do. The Goal on
which a comment arrived is context, not a reason to switch tasks. A correction
or stop takes effect now.

Use the supplied receipt command and confirmation instructions. When these are
absent or unclear, read the [connection interface](../workspace/connect.md).
For an independent later request, defer only when that interface supports and
confirms durable deferment. Otherwise keep it in the current work plan and
handle it at the next useful checkpoint; do not promise automatic redelivery.
Intake alone does not need a new Goal, Brief or checklist.

Claim the input when beginning its work and use the selected interface's work
selection when available. Never blindly retry an uncertain receipt or enqueue
another copy. Check its supported recovery path. Preserve other queues and
manual pauses. Skip completed events, and record completion or failure only
for work actually handled. These receipts do not mark a Goal Done.
