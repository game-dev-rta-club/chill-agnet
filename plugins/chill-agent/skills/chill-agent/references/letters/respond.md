# Respond to a Letter

Use this when feedback answers or comments on a question. Leave the resulting
agreement and next action clear, including anything still unresolved.

Read the question, its reply and relevant later feedback together. Goal readers
include the original question for a reply even when it is outside the current
conversation page. Referenced Brief versions explain what an annotation meant;
the current scope and subsequent corrections still govern the work.

Determine what the user actually decided. Acknowledgement, a new suggestion and
approval of an action have different effects. Reflect a changed agreement in
the Goal or Brief and respond in Conversation. Resume the work that the reply
actually enables while preserving unrelated waiting conditions and pauses.

A Letter reply can close its Web-list item automatically; ordinary comments do
not. Recheck the question and current discussion before manually using
`goal close-letter`. Close it when no more reply is needed. Closure acknowledges
the question, not authorization or achievement. If an essential part remains
unanswered, ask a focused follow-up rather than silently treating it as resolved.
