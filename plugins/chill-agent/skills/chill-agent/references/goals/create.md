# Create a Goal

Use this when a new request needs a shared destination. Leave a Goal whose title,
criteria and scope let the user and another agent understand what is being
pursued and what work is currently entrusted.

Start with the user's desired change and the agreement already in the conversation.
For example, first-time visitors being able to book without calling is an
outcome; researching booking tools may be the current scope toward it. Ask early
about consequential unknowns, bringing a concrete recommendation. Do not turn
routine implementation choices into a questionnaire.

Check whether an existing Goal already represents the outcome. Update that Goal
when it does; create a child only for a meaningful contributing outcome that
benefits from its own discussion or independent progress. Small tasks can stay
in your working plan.

Use the verified connection interface for Root creation and its confirmation
requirements. Establish a missing connection before attempting that operation. Children and ordinary updates use the shared
`goal create --help` or `goal update --help`. Put the destination in the
title, observable success in the criteria, and the work currently agreed in the
scope. Keep the developing explanation in the Brief and share the proposal or
result in Conversation. Recording it preserves understanding; it does not
supply missing implementation permission.
